# PHYSIO MARKET

**Internal Physiotherapy Market Intelligence Platform – Equipment, Suppliers, Brands, Pricing, Import & Logistics.**

منصة داخلية مستقلة لجمع وتنظيم وتحليل بيانات سوق أجهزة ومستلزمات العلاج الطبيعي، مع التركيز على السوق المصري والمصانع والموردين الدوليين.

## الحالة الحالية

نسخة تأسيسية (Prototype) بواجهة عربية RTL وبيانات بحث أولية. لا يوجد حتى الآن خادم خلفي أو تسجيل دخول أو قاعدة بيانات تشغيلية متصلة.

## تشغيل الواجهة

افتح `index.html` مباشرة في المتصفح. لا تحتاج النسخة الحالية إلى تثبيت حزم.

## أقسام المنصة

- لوحة المؤشرات.
- الأجهزة والمعدات.
- المستهلكات والملحقات.
- الشركات المصرية.
- الموردون والمصانع الصينية.
- العلامات التجارية والوكلاء والموزعون.
- عروض الأسعار.
- الشحن والاستيراد.
- التسجيل والامتثال.
- المصادر والتحقق.
- دليل الأكواد الموحد.

## هيكل الملفات

- `index.html`: هيكل التطبيق.
- `styles.css`: التصميم المتجاوب والهوية البصرية.
- `data.js`: بيانات تجريبية/استكشافية أولية.
- `app.js`: التنقل والبحث وعرض الجداول وتصدير CSV.
- `database/schema.sql`: مقترح مبدئي لهيكل قاعدة بيانات PostgreSQL.

## سياسة جودة البيانات

حالات السجلات:
- `verified`: تم التحقق بمصدر مباشر حديث.
- `needs_review`: يحتاج إلى مراجعة أو تواصل مباشر.
- `platform_reference`: سعر أو معلومة استرشادية من منصة، وليست عرضًا ملزمًا.
- `reference`: مرجع أو مستند للاستدلال.

**لا تعتبر أسعار المنصات عروض أسعار من المصنع. ولا تعتبر الإشارة إلى علامة تجارية دليلًا على وجود وكالة أو تفويض معتمد.** يجب تسجيل تاريخ الرصد والرابط والمصدر وشروط السعر والحد الأدنى للطلب عند توفرها.

## تنبيه أمني

كون مستودع GitHub خاصًا لا يجعل أي نسخة منشورة من الواجهة آمنة تلقائيًا. لا تضع كلمات مرور أو مفاتيح API أو عروضًا سرية أو بيانات تفاوض خاصة داخل ملفات الواجهة. قبل الاستخدام الفعلي متعدد المستخدمين، يجب إضافة Backend ومصادقة وصلاحيات وصول وتخزين محمي وسجل تدقيق ونسخ احتياطي.

## خارطة الطريق

1. اعتماد قاموس البيانات والأكواد.
2. تدقيق الموردين المصريين ومصادر المصانع الصينية.
3. بناء نماذج إضافة وتعديل السجلات وربط المصادر.
4. إضافة Backend وقاعدة بيانات ومصادقة.
5. إضافة سجل عروض الأسعار والمقارنة والتنبيهات.
6. تطوير وحدة الاستيراد والتكلفة النهائية والامتثال التنظيمي.
